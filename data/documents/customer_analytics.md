
# Customer Analytics Guide

Customer segmentation groups customers with similar observed characteristics.
Useful features can include purchase frequency, completed revenue, average
transaction value, subscription fee, acquisition channel, and recency.

A segment is a descriptive grouping, not a guaranteed prediction of future
behavior. Segment names should be assigned only after reviewing the profile
of each cluster.

Customer lifetime value estimates the value a customer may generate over
a specified horizon. Any estimate should document its time horizon and
assumptions.

Customer churn must be defined using a specific observation window and
future outcome window. Features used for prediction must be measured before
the outcome window to prevent temporal data leakage.
